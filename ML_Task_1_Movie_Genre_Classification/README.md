# Movie Genre Classification using Machine Learning

## 📌 Description
This project focuses on classifying movies into different genres based on their plot descriptions using Machine Learning and Natural Language Processing (NLP).

## 🎯 Objective
To build a machine learning model that can automatically predict the genre of a movie from its textual description.

## 🧠 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (TF-IDF)
- Google Colab

## 📂 Dataset
The dataset consists of movie plot summaries along with their respective genres.

## ⚙️ Model Used
- TF-IDF Vectorizer
- Naive Bayes Classifier

## 📊 Output
The trained model predicts genres such as:
- Drama
- Comedy
- Action
- Thriller

## 🚀 Conclusion
This project demonstrates how Machine Learning and NLP techniques can be used to classify movie genres effectively based on text data.
