# Spam SMS Detection using Machine Learning

## 📌 Description
This project is a Machine Learning model that classifies SMS messages as Spam or Not Spam (Ham) using Natural Language Processing techniques.

## 🛠 Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- TF-IDF Vectorizer
- Naive Bayes Algorithm

## 📂 Dataset
SMS Spam Collection Dataset (spam.csv)

## ⚙️ Workflow
1. Import required libraries
2. Load and preprocess dataset
3. Convert text data using TF-IDF
4. Train the model using Naive Bayes
5. Evaluate model accuracy
6. Predict new SMS messages

## 📊 Result
Model achieved approximately **96% accuracy**.

## 🚀 Example Prediction
Input:  
"You won a free lottery prize! Call now"

Output:  
**Spam Message**
