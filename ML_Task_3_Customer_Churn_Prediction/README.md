🔹 Description
This project predicts whether a customer will leave a company (churn) or stay. Customer churn prediction helps businesses take action to retain customers and reduce revenue loss.

🔹 Technologies Used
	•	Python
	•	Pandas
	•	NumPy
	•	Scikit-learn
	•	Matplotlib
	•	Seaborn

🔹 Steps Performed
	1.	Data loading and preprocessing
	2.	Handling categorical variables
	3.	Feature scaling
	4.	Train-test split
	5.	Logistic Regression model training
	6.	Model evaluation using Accuracy, Confusion Matrix, Classification Report

🔹 Model Performance
	•	Accuracy: 81.6%
	•	The model predicts non-churn customers very well.
	•	Churn prediction recall is lower due to dataset imbalance.

🔹 Conclusion
This model can help businesses identify customers likely to leave and take preventive measures.
